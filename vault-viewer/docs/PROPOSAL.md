# 隨身密閱 企劃草案（v0，討論用）

## 1. 目標

- 把多個文件（含資料夾結構）加密成**一個檔案**，檢視器內嵌其中，收件人不必安裝任何東西。
- 開啟需要兩個要素：**密碼**（知道的東西）+ **金鑰**（持有的東西，例如金鑰檔）。
- 開啟後是檔案總管式介面：左側樹狀列表、右側預覽。
- 封存者可設定使用條件：可開啟次數、到期日等。

## 2. 先講清楚的限制（重要）

1. **離線條件只能「防君子」**：檔案可以被複製、電腦時鐘可以調回去、開啟次數記在本機可以被清掉。
   只要收件人同時握有密碼和金鑰，技術上就能繞過檢視器自己解密。
   要真正強制「次數／期限／遠端撤銷」，必須有一台線上服務握住一部分金鑰（見 §5 線上模式）。
2. **擋不住截圖與翻拍**：內容一旦顯示在螢幕上就可能被拍下。可用的是嚇阻手段：
   浮水印（收件人名稱＋時間）、停用複製／列印／下載、閒置自動上鎖。
3. 加密本身（AES-256-GCM）沒有破解疑慮，風險在於密碼強度與金鑰保管。

## 3. 型態選項

| 方案 | 說明 | 優點 | 缺點 |
|---|---|---|---|
| **A. 單一 HTML 檔（建議）** | 檢視器程式 + 加密資料全部塞進一個 `.html`，雙擊用瀏覽器開 | 真正免安裝、Windows/Mac/手機都能開、不會被防毒擋、易於寄送 | 單檔建議 < 300MB；次數紀錄只能存在瀏覽器裡（換瀏覽器就重置） |
| B. 單一可執行檔（.exe） | 檢視器程式後面附加加密資料 | 可處理更大檔案、本機控制較多 | 需分 Windows/Mac 版、未簽章 exe 會被 SmartScreen/防毒警告、收件人較不敢開 |
| C. 檢視器 + 獨立資料檔 | 兩個檔案 | 檢視器可重複使用 | 不符合「一個檔案」需求 |

建議先做 **A**，未來若有大檔需求再評估 B。

## 4. 架構草案（方案 A）

### 4.1 兩個工具
- **打包器**（也是一個離線 HTML 頁面，或命令列工具）：拖入檔案／資料夾 → 設定密碼、產生或選擇金鑰檔、設定條件 → 輸出 `xxx.vault.html`。
- **檢視器**：就是輸出的那個 `.html` 本身。

### 4.2 加密設計
- 主金鑰 = HKDF( Argon2id(密碼, salt) ‖ 金鑰檔內容 )；兩者缺一不可。
- 每個檔案各自以 AES-256-GCM 加密（各自 nonce），點到哪個才解哪個，大量檔案也不卡。
- 檔名、資料夾結構、使用條件放在**加密的索引（manifest）**裡：沒有密碼＋金鑰連檔名都看不到，
  也無法竄改條件（GCM 驗證會失敗）。
- 金鑰檔：32 bytes 隨機值，可輸出成 `.key` 檔或一串文字／QR Code。
  建議「檢視器」與「金鑰」與「密碼」走不同管道傳遞。

### 4.3 使用條件（可組合）
- 有效期限（起始日／到期日）
- 可開啟次數（每次成功解鎖算一次）
- 密碼錯誤次數上限 → 鎖定
- 單次閱覽時間上限／閒置自動上鎖
- 浮水印文字、是否允許下載原檔、是否允許列印
- 「首次開啟綁定此裝置」（離線下也只是防君子）

### 4.4 介面
- 解鎖畫面：密碼欄 + 選擇金鑰檔（或貼上金鑰文字）
- 主畫面：左側樹狀檔案列表＋搜尋；右側預覽；上方顯示剩餘次數／到期日
- 預覽支援（依階段）：
  - P0：文字、Markdown、程式碼、圖片、PDF
  - P1：影片、音訊、Word(.docx)、Excel(.xlsx)
  - 其他類型：顯示資訊，依條件決定是否可下載

## 5. 線上模式（選配，P2）

金鑰拆成三份：密碼、金鑰檔、**伺服器持有的金鑰分片**。
每次開啟時向伺服器（例如 Cloudflare Workers，免費額度即可）要分片，伺服器檢查期限／次數後才發。
- 真正強制次數與期限，用不同瀏覽器或複製檔案都繞不過
- 可**遠端撤銷**、查看開啟紀錄
- 代價：開啟時必須連網、需要維護一個小服務

## 6. 階段

- **P0**：打包器 + 檢視器（單一 HTML）、密碼 + 金鑰檔、樹狀列表、基本預覽、到期日與次數（離線版）
- **P1**：浮水印、禁止複製／列印、閒置上鎖、Office／影音預覽、錯誤次數鎖定
- **P2**：線上模式（強制次數／期限、遠端撤銷、開啟紀錄）

## 7. 待討論

1. 用途：自己隨身備份私密文件？還是分享給別人看（要限制對方）？
2. 收件人用什麼裝置開？（Windows／Mac／手機）
3. 常見檔案類型與總大小？
4. 次數／期限：離線「防君子」就夠，還是需要線上模式的真正強制？
5. 金鑰形式偏好：金鑰檔、一串文字、QR Code？
6. 打包器要用網頁介面，還是命令列就好？
