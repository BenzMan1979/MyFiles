# 3D 象棋：楚河漢界·名將對弈（暫定）

瀏覽器 3D 中國象棋：單機雙人／連線雙人／AI 對戰，雙方各選一個國家，棋子由該國歷史名人擔任，
將死對方時由出手的人物放出全畫面絕招，結算時再由勝方主帥收尾。

企劃與決策紀錄：[docs/PROPOSAL.md](docs/PROPOSAL.md)

## 目前進度：P0 完成

- 完整象棋規則引擎（蹩馬腿、塞象眼、炮架、將帥對臉、將死、困斃、長將判負、重複局面、六十回合限著）
- Three.js 3D 棋盤與棋子，選子顯示可走位置、可吃目標標紅
- 單機雙人：悔棋、認輸、翻轉視角、俯視／立體切換、自動翻轉、中文棋譜（炮二平五／馬８進７）
- 桌機與手機（觸控）皆可操作

下一步：P1 陣營選擇、人物資料、懸停介紹卡、立牌棋子。

## 開發

```bash
npm install
npm run dev        # 開發伺服器
npm test           # 規則引擎測試
npm run build      # 輸出到 dist/，可直接放 GitHub Pages
```

## 結構

```
src/core/    規則引擎（純邏輯、有測試）：fen / rules / game / notation
src/render/  Three.js 場景、棋盤、棋子、動畫
src/ui/      HUD（回合、棋譜、按鈕、結算）
src/main.ts  單機雙人控制器
```
